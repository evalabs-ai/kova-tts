# Zero-shot preset voices

Fifty reference clips the demo offers as ready-made zero-shot voices: pick one and the model
continues in that speaker, no recording needed. `metadata.csv` gives each `voice_NN.flac`'s
transcript in its `text` column. Cloning continues the reference, so that transcript has to match
the audio word for word, and it does.

None of these are recordings of a person. Every clip was generated by a Kova base checkpoint
prompted with no voice at all, which makes the model invent a speaker on each sample:

1. 200 original sentences, 5 samples each (1000 clips, seeded per clip).
2. Kept only clips that Whisper large-v3 transcribes back to their sentence exactly, that last
   4-15 s, and that score UTMOS >= 3.5 and DNSMOS OVRL >= 3.2 (854 of 1000).
3. Picked 50 by greedy farthest-point selection on WavLM-ECAPA speaker embeddings (the
   seed-tts SIM model), one clip per sentence, so no two presets sound alike: mean pairwise
   similarity 0.17 and closest pair 0.40, against 0.32 and 0.76 for a random 50.

Besides `file_name` and `text`, `metadata.csv` keeps, per voice, the source clip, its seed,
duration, UTMOS, DNSMOS and its similarity to the nearest other preset.

The clips are 48 kHz mono 16-bit FLAC. Any directory laid out the same way -- audio files plus a
`metadata.csv` with `file_name` and `text` columns -- can replace this one with
`kova-tts demo --zero-shot-dir`.
